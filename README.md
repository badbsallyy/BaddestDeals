# BaddestDeals

Eine moderne Deals und Angebote Website mit atemberaubendem, futuristischem Design für eine junge Zielgruppe.

## 🚀 Features

- **Modernes UI/UX**: Futuristisches Design inspiriert von Top Framer.com Websites
- **Smooth Animationen**: Powered by Framer Motion für flüssige Übergänge und Interaktionen
- **Responsive Design**: Optimiert für alle Geräte (Mobile, Tablet, Desktop)
- **Deal-Übersicht**: Übersichtliche Kategorisierung und Filterung von Angeboten
- **Newsletter**: E-Mail-Anmeldung für exklusive Deals
- **Scroll-Animationen**: Parallax-Effekte und Fade-in Animationen
- **Dark Theme**: Elegantes dunkles Design mit Gradient-Akzenten

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) mit App Router
- **Sprache**: TypeScript
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animationen**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **UI Components**: Custom components inspiriert von Aceternity UI

## 📦 Installation

```bash
# Dependencies installieren
npm install

# Development Server starten
npm run dev

# Production Build erstellen
npm run build

# Production Server starten
npm start
```

## 📁 Projektstruktur

```
src/
├── app/                    # Next.js App Router
│   ├── globals.css        # Globale Styles
│   ├── layout.tsx         # Root Layout
│   └── page.tsx           # Homepage
├── components/
│   ├── sections/          # Sektionen (Hero, Deals, Footer, etc.)
│   └── ui/                # Wiederverwendbare UI-Komponenten
├── data/
│   └── deals.ts           # Deal-Daten
└── lib/
    └── utils.ts           # Utility-Funktionen
```
